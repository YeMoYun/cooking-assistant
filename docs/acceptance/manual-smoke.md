# 本地手动验收清单

按以下顺序完成一轮即可，不需要反复运行自动化测试：

- [ ] 启动脚本成功打开 `http://localhost:4173`，局域网其他设备无法访问端口。
- [ ] 食谱页一屏显示多张简略卡片，搜索后可打开单道食谱。
- [ ] 食谱详情能看到食材、完整步骤；视频失败时文字教程仍完整。
- [ ] 冰箱照片识别结果先编辑再确认，拒绝时不写入库存。
- [ ] 两道菜生成购物清单，确认前不写入，确认后能勾选。
- [ ] AI 改菜谱显示差异和安全提醒，确认后原菜谱不变。
- [ ] 配置 DeepSeek 或通义千问 Key 后连接测试成功；刷新页面不要求重复输入 Key。
- [ ] 助手文本问答产生增量输出；切换上下文开关后只发送所选本地数据。
- [ ] 点击“打断并说话”停止旧网络流和旧朗读；拒绝麦克风权限后文本输入仍可用。
- [ ] 助手生成的购物清单或笔记显示确认卡，未确认前业务数据不变。
- [ ] 断开外网后仍能搜索、打开食谱和查看文字步骤，AI/视频提示不可用。
- [ ] 清空本地数据后收藏、库存、清单、会话和模型配置消失，食谱仍存在。
